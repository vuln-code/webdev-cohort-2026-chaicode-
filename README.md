#  Professional HTML-Only Resume

A sleek, single-page resume website built strictly with **semantic HTML**. This project demonstrates how to achieve professional UI layout, structural hierarchy, and data organization without the use of CSS or external frameworks.

---

##  Project Goals
The objective was to build a resume that is readable, organized, and visually clear using only the native capabilities of HTML. The focus remained on:
* **Structural Integrity:** Using semantic tags for accessibility.
* **Layout Alignment:** Utilizing tables and attributes for consistent spacing.
* **User Experience:** Ensuring information is scannable and logically ordered.

##  Key Features
* **Clean Header:** Centered name and contact info for immediate impact.
* **Organized Experience:** Career history formatted in tables to keep dates and roles perfectly aligned.
* **Technical Skills:** A structured grid of competencies for quick scanning.
* **Project Showcase:** Hyperlinked project titles with concise descriptions.
* **Responsive-ish Design:** Centered container table to ensure readability on wider screens.

---

##  Evaluation Parameters
| Parameter | Implementation Strategy |
| :--- | :--- |
| **UI Layout** | Used a master table container to mimic a physical resume page. |
| **Spacing** | Leveraged `cellpadding` and `<br />` tags to create white space. |
| **Visual Clarity** | Strategic use of `<h1>` through `<h4>` and `<hr>` dividers. |
| **Semantics** | Implemented `<header>`, `<main>`, `<section>`, and `<address>` tags. |

---

##  Preview
> **Note:** The layout uses a 1:1 replica of standard professional resume formats, ensuring that even without CSS, the document remains "printer-friendly" and professional.
